technique 01 · the fan

transform: rotate() + transform-origin

Rotating pivots around the element's centre by default. transform-origin moves that pivot — which is the difference between a tidy fan and a messy pile.

.card {
  transform: rotate(-8deg);
  transform-origin: bottom center;
}
rotation spread8deg
transform-originbottom center

Each card gets the same rule — only its multiplier differs (−2, −1, 0, 1, 2), so the spread slider drives all five at once.
center 400px puts the pivot 400px below each card — an off-element point. That is what bends a flat row into an arc.

technique 02 · the curve

An oversized circle, in the background colour

To replace a straight edge with a curve, don't try to bend the element. Lay a much bigger circle on top, paint it the page colour, and let it cover the edge.

.curve-mask {
  position: absolute;
  bottom: -300px;
  left: 50%;
  transform: translateX(-50%);
  width: 900px;
  height: 400px;
  border-radius: 50%;
  background: var(--page-bg);
}
bottom (how far pushed down)-300px
width (how shallow the curve)900px

This same trick works at the seam between any two page sections, not just under images. Wider circle = shallower curve.

technique 03 · containment

overflow: hidden vs visible

Use hidden to keep something in its box — glows, fanned images poking out. Use visible when you want a child to escape on purpose, like a product breaking out of a card.

.wrapper 
/* same markup, one property apart */
.wrapper-a { overflow: hidden;  /* clipped */ }
.wrapper-b { overflow: visible; /* escapes */ }
hidden
visible

The blue box is deliberately too small for the fan. Flip the switch and watch the cards spill straight out of it. That spill is exactly what hidden is for — and exactly what you want when a product image should break out of a card.

technique 04 · the glow

filter: blur()

Blur turns a plain gradient rectangle into a soft glow. That's how atmospheric light streaks behind hero text are made — with no image asset at all.

.glow {
  width: 500px;
  height: 150px;
  background: linear-gradient(90deg,
      transparent, rgba(255,255,255,.5), transparent);
  filter: blur(40px);
  transform: rotate(-15deg);
}
blur radius40px

Drag to 0 and it's just a gradient rectangle. Everything atmospheric about it is the one blur value.

technique 05 · the fade

mask-image with a gradient

A mask hides parts of an element using a gradient: black stays, transparent disappears. It's how a photo dissolves into the page, and how text can look like it sits behind one.

.photo {
  -webkit-mask-image: linear-gradient(to bottom,
             black 60%, transparent 100%);
  mask-image: linear-gradient(to bottom,
             black 60%, transparent 100%);
}
black ends at60%
fully transparent at100%
directionto bottom

Bring the two stops close together for a hard edge; push them apart for a long, soft dissolve. The chequerboard behind is the page showing through.

technique 06 · the headline

clamp() for fluid type

A fixed font-size breaks on very small and very large screens. clamp(min, preferred, max) lets text scale with the viewport but never past safe limits.

Golden Hour

container 900px  ·  computed font-size 72px 

h1 { font-size: clamp(2rem, 8vw, 7rem); }

/* min 32px · preferred 8% of width · max 112px */
simulated viewport width900px

Watch the readout: below 400px it pins to the 32px floor, above 1400px it pins to the 112px ceiling, and in between it scales smoothly.
Demo note: the slider stands in for the viewport, so the text keeps growing even once the dashed box runs out of room on this screen — exactly what 8vw does on a monitor wider than the box.
