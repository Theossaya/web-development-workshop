LEARN
A fair shuffle, known as the Fisher-Yates shuffle:

```js
function shuffle(list) {
  const copy = [...list];
  for (let i = copy.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [copy[i], copy[j]] = [copy[j], copy[i]];
  }
  return copy;
}
```

A knockout bracket needs 2, 4, 8, 16 or 32 players. Find the next of those sizes, and the difference is how many byes you need:

```js
let size = 2;
while (size < players.length) size *= 2;
const byes = size - players.length;
```

Give the byes out first, so no match ever has two byes. With five players you need three byes, so round one is three players each against a bye, then the last two players against each other. A player against a bye goes straight through to round two.

TEXT
You now have a working community site built from nothing but HTML, CSS and JavaScript, and you understand every line of it. These are the next steps, roughly in order.

### A server and a database

Lobby's biggest limit is that everything people save stays on their own phone. Real accounts, shared tournament registrations and a chat everyone can read need a server and a database. The two usual routes are to learn Node.js and write your own server, or to use a service such as Firebase or Supabase that gives you accounts and a database without running a server yourself. Either way, your Lobby front end stays almost exactly as it is.

### Git, properly

If you have been uploading through the GitHub website, learn Git on a laptop: branches, commits with good messages, and going back to an earlier version when something breaks.

### A framework, later

React, Vue and Svelte are popular because they make the `state` and `render()` pattern from boss week 4 easier on large sites. You already understand the problem they solve, which makes them much easier to learn. Do not start one until plain JavaScript feels comfortable.

### Keep building

The fastest way to improve now is to build a second, different site from an empty folder, without this guide open. A booking page for a barber, a menu for a local restaurant, or a results site for your school's football league. Pick something a real person would use, and ask them what they need before you start.
