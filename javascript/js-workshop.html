// 00 hook · the deal five hours, one break

The deal for today.

  1. Store a value and change it later.
  2. Write a function and call it.
  3. Make the code decide between two paths.
  4. Hold a list, and do something to every item in it.
  5. Model a real thing as an object.
  6. Find any element on the page and change it.
  7. Run your own code when someone clicks or types.
  8. Read an error message and fix what it points at.

The method, again

predict → type → run → break → explain. Every single concept. You will guess what the code prints before we run it, and you will be right more often than you expect.

Nothing today is memorised. There is a reference at the back of this deck and there will be one on the wall. Professionals look things up constantly — the skill is knowing what to look up.

Two things we are deliberately not doing today: frameworks, and anything that talks to a server. Both are much easier once this is solid.

Printing shows you. Returning hands it back.

console.log is a window. return is a door.

Do not start again. Find out what is actually true.

The computer is not being difficult. It is doing exactly what you wrote, and it will tell you what that was if you ask.
  1. Read the red line. All of it, including the line number.
  2. Go to that line. The fault is usually there or just above.
  3. Log the thing before the dot. console.log(button) — is it an element, or null?
  4. Check the spelling of every name against where it was defined.
  5. Change one thing. One. Then run again.
  6. Say why it worked out loud before moving on.
